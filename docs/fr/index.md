## Comment ça marche {#how-it-works}

<p class="lead">Pensé pour la soirée elle-même : un invité a vingt secondes et une main libre. Pensé pour le lendemain matin : les organisateurs veulent toutes les photos, triées, privées.</p>

<div class="home-steps">
<div>

### Scanner {#scan}

Imprimez la carte, une par table. Le QR code ouvre une page web sur n'importe quel téléphone.

</div>
<div>

### Photographier {#shoot}

L'appareil photo s'ouvre tout de suite. Un geste et la photo est partie, même avec une connexion faible.

</div>
<div>

### Garder {#keep}

Tout arrive dans votre album, avec le nom de qui l'a prise. Validez, projetez, téléchargez, envoyez l'album à vos invités.

</div>
</div>
</section>

<section class="home-section home-row">
<div>

## Les invités ne voient jamais que leurs propres photos. {#guests-only-ever-see-their-own-photos}

<p class="lead">L'album appartient aux organisateurs. Chaque requête de photo est vérifiée, un lien copié n'ouvre rien ailleurs, et la position GPS comme les métadonnées de l'appareil sont retirées de chaque envoi. Défis, filtres et livre d'or donnent aux invités autre chose à faire que faire défiler.</p>

## L'installer en une minute {#install-it-in-a-minute}

<p class="lead">Un conteneur, un volume. Les téléphones n'ouvrent l'appareil photo que sur des pages HTTPS : placez-le derrière un reverse proxy avec un certificat, le <a href="./deployment">guide de déploiement</a> donne des configurations Caddy, Traefik et nginx.</p>

```bash
docker run -d --name guestroll \
  -p 3000:3000 \
  -v guestroll-data:/data \
  -e ADMIN_PASSWORD='choose-a-long-password' \
  -e PUBLIC_URL='https://photos.example.com' \
  ghcr.io/achedon12/guestroll:latest
```

Ouvrez ensuite `/admin`, connectez-vous en tant que `admin`, créez un évènement et imprimez son QR code.
