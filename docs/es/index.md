## Cómo funciona {#how-it-works}

<p class="lead">Pensado para la propia noche: un invitado tiene veinte segundos y una mano libre. Pensado para la mañana siguiente: los anfitriones quieren todas las fotos, ordenadas y privadas.</p>

<div class="home-steps">
<div>

### Escanea {#scan}

Imprime la tarjeta, una por mesa. El código QR abre una página web en cualquier móvil.

</div>
<div>

### Dispara {#shoot}

La cámara se abre al instante. Un toque y la foto va de camino, incluso con mala conexión.

</div>
<div>

### Guarda {#keep}

Todo llega a tu álbum, con el nombre de quien hizo cada foto. Aprueba, proyecta, descarga, envía el álbum a tus invitados.

</div>
</div>
</section>

## Cada invitado solo ve sus propias fotos. {#guests-only-ever-see-their-own-photos}

<p class="lead">El álbum es de los anfitriones. Los retos, los filtros y un libro de visitas dan a los invitados algo que hacer además de deslizar.</p>

## Instálalo en un minuto {#install-it-in-a-minute}

<p class="lead">Un contenedor, un volumen. Los móviles solo abren la cámara en páginas HTTPS: ponlo detrás de un proxy inverso con un certificado; la <a href="./deployment">guía de despliegue</a> incluye configuraciones para Caddy, Traefik y nginx.</p>

```bash
docker run -d --name guestroll \
  -p 3000:3000 \
  -v guestroll-data:/data \
  -e ADMIN_PASSWORD='choose-a-long-password' \
  -e PUBLIC_URL='https://photos.example.com' \
  ghcr.io/achedon12/guestroll:latest
```

Después abre `/admin`, inicia sesión como `admin`, crea un evento e imprime su código QR.
